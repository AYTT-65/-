# متجر مركز الايباد

نظام عربي خفيف لإدارة المنتجات والمخزون وتسجيل المبيعات، مبني باستخدام Flask وSQLite.

## التشغيل

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py app.py
```

ثم افتح: http://127.0.0.1:5000

تبدأ الصفحة بتسجيل اسم الزبون ورقم التواصل، ثم تظهر بطاقات المنتجات مع خيار الحجز. لإدارة المنتجات والمبيعات افتح `/dashboard`، ومن هناك يمكنك إضافة صورة المنتج ومواصفاته وسعره ومخزونه.
